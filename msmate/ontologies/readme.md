# Local ontology files

mzML files provide ontology URLs - these links can be outdated or broken (e.g. older files reference 
legacy SourceForge URLs). Therefore, local copies of the two main ontologies are provided here. These ensure 
stable and reproducible mzML file parsing.

## PSI-MS ontology
HUPO Proteomics Standards Initiative (PSI) mass spectrometry controlled vocabulary.

- format-version: 1.2  
- data-version: 4.1.246  
- accessed: 2026/04/17  
- web-link: https://raw.githubusercontent.com/HUPO-PSI/psi-ms-CV/master/psi-ms.obo
- local file: `psi-ms.obo`

## Unit Ontology (UO)
Controlled vocabulary for units used in mass spectrometry metadata.

- format-version: 1.2  
- data-version: releases/2026-01-16  
- accessed: 2026/04/17  
- web-link: http://purl.obolibrary.org/obo/uo.obo
- local file: `uo.obo`
